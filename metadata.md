## Description
RustChain's RIP-200 uses deterministic round-robin participation, while RIP-PoA adds hardware fingerprint attestation to distinguish physical CPUs from virtualized or emulated identities.

This explainer walks through the public protocol specification: fingerprint checks, 1-CPU-1-Vote rotation, antiquity multipliers, time-aged reward weighting and the threat model.
